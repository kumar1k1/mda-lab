# Где остановились (25.10.2026, после версии 0.6.3)

Пользователь выбрал два способа уменьшить базу на диске (варианты 1 и 2). Работа приостановлена по его просьбе — продолжить с них.

## 1. Сжатие колонок на диске (ещё не начато)
- Замер на датамайнинге (scratchpad/obs/o3): колонки 81 МБ (73% базы), реплеер 31 МБ. `gzip -1` по колонкам: 82 → 17 МБ (≈ 4,8×).
- План: файл колонки `c_<имя>.z` — порции по 16 384 строки, deflate-raw (можно с перестановкой байтов для i32/f64),
  в конце — индекс смещений порций и подвал (n, строк в порции, размер элемента, число порций, сигнатура).
- Чтение старых `c_<имя>.bin` остаётся (совместимость); выбор по наличию файла.
- Места, которые читают/пишут колонки: `parser/table.js` (ColumnReader, ColumnWriter, mergeColumn, patchColumn — для EV: распаковать, поправить, записать целиком, readRange, readAt),
  `parser/store.js` (colBytes, playersCc, playerCol, replays), `parser/migrate.js` (readCol/writeCol), `parser/ingest.js` (scan, applyEv), `preview/pack-v3.js` (читает c_*.bin напрямую), `tools/audit-ev.js`.
- Временные колонки загрузки (tmp-ingest, SpillColumn) можно оставить несжатыми.

## 2. Двоичная запись реплеера (кодировщик написан, не подключён)
- `app/parser/rpbin.js`: encodeRec(rec) → deflate(двоичный вид | JSON, если двоичный не восстанавливает запись один в один), decodeRec2(z) читает оба вида.
- Следующий шаг: замерить размер и проверить совпадение на всех записях pv10 (скрипт был готов, пользователь прервал запуск).
- Подключить: parse-worker (вместо deflate JSON), store.decodeRec (при meta.rpz = 2), ev-pool, migrate.js (у него свой inflate+JSON), meta.rpz = 2 у новых баз.

## 3. Обновление старой базы при запуске
- Через parser/migrate.js (как досчёт cbs/fcb/ant): сжать колонки; переписать rp_*.dat в двоичный вид и обновить ссылки rpp/rpo/rpl в обеих таблицах (карта старая ссылка → новая).
- В ingest: если старая база ещё не обновлена (rpz != 2) — сначала обновить, потом дописывать.

## 4. Проверка и выпуск
- Сравнить старую и новую версию на одних и тех же раздачах (все колонки, список игроков, записи реплеера), Electron-тест (e2e/bgev.js, e2e/mig.js), замер размера и скорости.
- Инсталлятор 0.7.0 (APPVER в build/installer.nsi и app/package.json), отправить пользователю.

Ожидаемый итог: база на загрузку 1,7 ГБ — около 0,45–0,5 ГБ вместо 1,5 ГБ. Оценка работы: 1,5–2,5 часа.
