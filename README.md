# MDA Lab — личный кабинет игрока (турниры)

Программа для Windows (Electron): загрузка истории раздач, вкладки статов, сводка по RFI,
матрица рук, реплеер раздач. Сейчас готова вкладка «Открытие (RFI)».

## Что где лежит

- `app/` — сама программа
  - `main.js`, `preload.js` — оболочка Electron
  - `parser/parse.js` — разбор историй раздач (PokerStars и экспорт GG/PokerDom в его формате, Winamax, WPN)
  - `renderer/` — интерфейс: `index.html`, `styles.css`, `app.js` (вкладки, RFI, сводка), `stats.js` (расчёт статов),
    `hands-ui.js` (окно матрицы, список раздач, реплеер), `replay.js` (кадры реплеера)
  - `data/my-base.json` — база героя (122 592 раздачи, без имён соперников)
  - `data/my-base-replays.json` — ход раздач-открытий для реплеера
- `tools/build-hero-db.js` — собрать базу из папки с историями раздач
- `preview/` — сборка онлайн-превью (`node preview/build.js`)
- `build/installer.nsi`, `build/icon.*` — установщик Windows (NSIS)

## Как продолжить в новом чате с Claude

1. Загрузите в чат этот архив (и при необходимости архив историй раздач).
2. Напишите: «Это мой проект MDA Lab, распакуй и продолжаем». README поможет быстро сориентироваться.

## Пересобрать базу из историй раздач

```
node tools/build-hero-db.js <папка_с_раздачами> app/data/my-base.json
```

## Решения, согласованные с HUD (Hand2Note)

- Позиции: от баттона CO, HJ, MP; при 5+ местах перед баттоном MP занимает два места; остальные — EP.
- RFI по стеку считается по открытиям не олл-ином (NAI).
- ISO: в колонке BB без блайнда против блайнда, в TOT — все; «/Fold» — фолд героя на лимп-рейз после изолейта.
- Ответ соперников на открытие — по первому действию соперника (19 / 55 / 26 на всей базе).
