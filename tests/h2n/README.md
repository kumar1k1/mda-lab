# Сверка с Hand2Note

Эталон — база пользователя в Hand2Note: **109 688 раздач, с повторами**.
Скриншоты и цифры Hand2Note, которые присылает пользователь, всегда считаются по этому количеству рук.

- 1 495 раздач GG — копии одной раздачи из двух выгрузок (разные номера раздачи, по-разному записано название турнира).
  Hand2Note считает их дважды. В программе с 0.7.9 они хранятся с отметкой `dup = 1`; по умолчанию фильтр «Повторы раздач» их убирает
  (108 193 раздачи), вариант «учитывать, как в Hand2Note» — оставляет (109 688).
- Поэтому сверка с Hand2Note — только при «учитывать, как в Hand2Note» (или на копии базы со всеми 109 688 раздачами).
- Присланные цифры записывать сюда (`reference.json`): стат, ситуация/позиция, фильтры, значение в Hand2Note, число возможностей, дата скриншота.
