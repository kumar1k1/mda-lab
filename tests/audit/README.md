# Сверка вкладок «Открытие», «Колд-колл», «3-бет», «Против 3-бета»

Скрипты открывают превью (`preview/MDA-Lab-preview.html` на http://127.0.0.1:8783, собранное из полной базы через `MDALAB_BASE`)
в Chromium через Playwright и сравнивают программу с независимым пересчётом по колонкам базы.

| Скрипт | Что проверяет |
|---|---|
| `3bet-numbers.js` | все числа вкладки «3-бет» (35 тыс. возможностей), в том числе тип 3-бета для 5 / 7 / 7.1 |
| `rfi-cc-v3b-numbers.js` | «Открытие» 1 и 8 по типам, «Колд-колл» 1/2, 7, 8, «Против 3-бета» 1, 2, 3, 5 под 9 сочетаниями фильтров раздела |
| `windows-vs-filters.js` | каждое окно при наведении во всех 4 вкладках: каждая раздача списка проходит фильтры шапки, стек и тип раздела (по таблице docs/filters.md) и ситуацию вкладки |
| `replayer-links.js` | реплеер по раздачам этих ситуаций: позиция и стек героя совпадают с базой |

Запуск: `node tests/audit/<скрипт>.js <папка для снимков>`. Ожидаемый итог — «расхождений 0» / «ошибок 0».
