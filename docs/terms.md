# Слова пользователя (как он называет части программы)

- **Окно первого типа** — всплывающее окно «Диапазон» (`showSzMx` / `pinSzMx`, windows.js): при наведении — матрица рук, раскрашенная по вашим действиям (фолд / колл / рейз / олл-ин); по клику закрепляется, в нём вкладки «Диапазон / Факт, BB / EV, BB» и список раздач справа.
- **Окно второго типа** — окно итога по рукам без диапазона (`showHandPop` / `pinHandPop`, hands-ui.js): матрица рук, окрашенная по результату; при наведении и при закреплении — в режиме, выбранном переключателем «EV, BB / Факт, BB» в таблицах (`VAL_MODE`), в закреплённом окне — свой переключатель факт / EV, клик по руке — раздачи и реплеер.
- **Карточка N раздела X** — блок с номером `#N` в разделе X.
- **Фильтры шапки** — рум, тип турнира, период, бай-ин, столы (действуют всегда); **фильтры раздела** — полоса под шапкой (ваш стек, тип, наше действие, тип банка, наша позиция), правило — docs/filters.md.
